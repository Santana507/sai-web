# Prompts SDD para BPVDA

| Fase | Prompt esencial |
|---|---|
| Constitución | Lee AGENTS.md y docs/constitution.md. Resume los límites de esta tarea. |
| Spec | Lee la spec activa. Propón requisitos verificables y marca dudas como [NECESITA ACLARACIÓN]. |
| Clarificación | Revisa requisito por requisito y enumera decisiones que requieran confirmación humana. |
| Plan | Convierte la spec en cambios pequeños, archivos afectados y estrategia de validación. |
| Tareas | Divide el plan en tareas pequeñas con prioridad, dependencia y Hecho cuando:. |
| Implementación | Ejecuta una sola tarea, conserva cambios existentes y valida al terminar. |
| Validación | Relaciona cada requisito con archivos, pruebas y comprobaciones manuales. |
| Cambio | Actualiza primero la documentación y después el código cuando cambie el alcance. |
