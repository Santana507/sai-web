# Constitución del proyecto BPVDA

Esta constitución define las decisiones que deben mantenerse aunque cambien las páginas, el diseño o la futura plataforma de publicación.

## Misión

Construir un sitio institucional claro, accesible, confiable y visualmente coherente para Buen Pastor Voz de Alerta, con una base que pueda evolucionar sin perder contenido ni trazabilidad.

## Principios innegociables

1. **Contenido aprobado:** no se publican datos institucionales inventados o no confirmados.
2. **Identidad con evolución controlada:** toda mejora visual debe proteger la identidad BPVDA y explicar su beneficio.
3. **Accesibilidad por defecto:** teclado, foco, contraste, jerarquía, textos alternativos y reduced motion forman parte del producto.
4. **Arquitectura simple:** el prototipo mantiene HTML, CSS y JavaScript compartidos mientras no exista una decisión aprobada para cambiar de plataforma.
5. **Experiencia responsive:** cada página debe ser usable en escritorio y móvil.
6. **Cambios trazables:** toda funcionalidad nueva tiene spec, plan, tareas y validación proporcional.
7. **Preservación:** los recursos y cambios existentes se conservan salvo que la tarea autorice su reemplazo.
8. **Seguridad y privacidad:** los formularios validan entradas y solicitan solo los datos necesarios.

## Fuente de verdad

1. Decisiones confirmadas por BPVDA.
2. Esta constitución y la spec activa.
3. clarifications.md y plan.md.
4. Contenido y comportamiento existentes del prototipo.
5. Suposiciones técnicas, siempre marcadas como pendientes.

## Alcance actual

- Prototipo estático multipágina.
- Ocho áreas institucionales navegables.
- Contenido visual y editorial procedente de bocetos y recursos aprobados.
- Mejoras graduales de claridad, accesibilidad, responsive, rendimiento y mantenimiento.

## Pendientes que requieren decisión

- Datos definitivos de dirección, teléfonos, correo y horarios.
- Prioridad de las próximas mejoras de diseño y contenido.
- Hosting y estrategia de publicación.
- Necesidad futura de un CMS, formulario persistente o integraciones.
